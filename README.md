# Wiki-Afroemics-Project-Content-and-Gender-Gap
This project is a live Wikidata-powered dashboard built with HTML and Wikidata SPARQL query that tracks gender representation and content gaps among African academics and scientists across 54 African countries.

The tool automatically identifies scholars connected to Africa through Wikidata statements such as country of citizenship, place of birth, country of residence, and other relevant properties. It then categorises and analyses the data by gender and country, checks whether each scholar has a corresponding Wikipedia article, and identifies gaps in Wikipedia coverage.

For scholars who do not yet have Wikipedia articles, the dashboard provides a gap explorer to help editors identify potential subjects for article creation and improve the visibility and documentation of African academics and scientists across Wikimedia projects.
